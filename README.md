# CampusLoop 🔄

CampusLoop is a campus marketplace where students can buy, sell, borrow, and swap items within their college community.

## Current Progress

- Created the homepage
- Developed the Marketplace page
- Added item categories and listings
- Created the Item Details page
- Added navigation between pages
- Implemented dynamic item details using URL parameters
- Created a Contact Seller interface

## Tech Stack

**Currently Using**
- HTML5
- CSS3
- JavaScript

**Planned Technologies**
- React.js
- Node.js
- Express.js
- MongoDB

**Development Tools**
- Visual Studio Code
- Git
- GitHub

## Project Status

🚧 CampusLoop is currently under development. The frontend is being developed first, followed by backend development and database integration.
